## Sistema Bancário Simples em Java

Este projeto consiste em um sistema bancário desenvolvido em Java com o objetivo de simular operações financeiras essenciais, como autenticação por senha, depósitos, saques e consulta de saldo. A aplicação foi criada para colocar em prática os principais conceitos da Programação Orientada a Objetos (POO), além de reforçar boas práticas de desenvolvimento e organização de código.

## 🚀 Funcionalidades

* Cadastro de conta bancária
* Validação de senha para acesso às operações
* Depósito em conta
* Saque com verificação de saldo disponível
* Consulta de saldo
* Mensagens de validação e tratamento de operações inválidas

## 📚 Conceitos e Matérias Praticadas

**Encapsulamento:** proteção dos atributos da conta através do uso de modificadores de acesso (`private`) e métodos getters/setters, garantindo maior segurança e controle dos dados.

* **Abstração:** modelagem dos elementos essenciais de uma conta bancária, representando apenas as características e comportamentos relevantes para o sistema.

* **Programação Orientada a Objetos (POO):** utilização de classes, objetos, atributos e métodos para representar entidades do mundo real.

* **Validação de Dados:** implementação de regras para autenticação por senha e verificação de saldo antes da realização de saques.

* **Métodos e Estruturas Condicionais:** uso de funções para organizar as operações do sistema e estruturas `if/else` para tomada de decisões.

* **Organização e Reutilização de Código:** separação de responsabilidades e criação de métodos específicos para cada operação bancária.

### 🎯 Objetivo do Projeto

Aplicar na prática os fundamentos da linguagem Java e da Programação Orientada a Objetos por meio da construção de um sistema bancário funcional, fortalecendo conhecimentos em lógica de programação, modelagem de classes, segurança básica e manipulação de dados.

### 🛠️ Tecnologias Utilizadas

* Java
* Programação Orientada a Objetos (POO)
* IntelliJ IDEA / Eclipse
* Git e GitHub para versionamento de código

> Projeto desenvolvido com foco educacional para consolidar conhecimentos em Java e preparar a base para sistemas mais robustos e complexos. 🚀💻
